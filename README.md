# NEXORA MVP — v0.2

NEXORA — HTML/CSS/JavaScript асосидаги мобилга мос веб-прототип.

## Нима ишлайди?
- Бўлимлар орасида ўтиш: лента, видео, чат, AI демо, LIVE, бозор, профиль.
- Пост қўшиш, лайк ва пост қидириш.
- Постлар, демо чат, демо AI суҳбати, маҳсулотлар ва профиль маълумотлари шу браузернинг `localStorage` хотирасида сақланади.
- Маҳсулот қўшиш ва JSON маълумотларини экспорт қилиш.
- Очиқ MP4 видео ҳаволасини браузерда кўриш (агар сервер рухсат берса).
- PWA manifest ва service worker; HTTPS орқали жойлаштирилганда илова сифатида ўрнатиш имкони браузерга боғлиқ.

## Ҳали мавжуд эмас
Бу тўлиқ ишлаб чиқаришга тайёр ижтимоий тармоқ эмас. Ҳақиқий аккаунт/парол, сервердаги база, қурилмалар ўртасида синхронлаш, бошқа одамларга хабар юбориш, видео файл юклаш/сақлаш, LIVE трансляция, ҳақиқий AI API, онлайн буюртма ва тўловлар йўқ. AI бўлими маҳаллий намунавий жавоблар беради.

## Тез синов
1. `index.html` файлини браузерда очиб кўринг. Баъзи PWA функциялари `file://` режимида ишламайди.
2. Пост ёзинг, маҳсулот қўшинг, саҳифани қайта юкланг — маълумотлар шу браузерда қолиши керак.
3. Бошқа телефон/браузерда маълумотлар автоматик кўринмайди, чунки сервер базаси йўқ.

## Интернетга жойлаш
### Вариант A — GitHub Pages
1. GitHub аккаунти очинг.
2. Янги public repository яратинг, масалан `nexora`.
3. `index.html`, `manifest.webmanifest`, `sw.js` файлларини repository root'ига юкланг.
4. Repository → Settings → Pages → Deploy from a branch → `main` ва `/ (root)` ни танланг.
5. Берилган HTTPS ҳаволани очинг.

### Вариант B — Netlify ёки Cloudflare Pages
Лойиҳа файлларини янги сайт сифатида юкланг ёки GitHub repository'га уланг. Build command талаб қилинмайди; publish directory — root (`/`).

## Кейинги ишлаб чиқиш босқичи
1. Backend ва база: Supabase/Firebase каби хизматни баҳолаш.
2. Auth: рўйхатдан ўтиш, email/телефон тасдиғи, пароль тиклаш.
3. Database: users, posts, likes, follows, messages, products.
4. Storage: расм ва видеолар.
5. Realtime чат.
6. AI API — фақат сервер томонидаги функция орқали; API калитини ҳеч қачон браузерга жойлаштирманг.
7. LIVE учун WebRTC ёки трансляция провайдери.
8. Тўловлар, хавфсизлик, модерация, махфийлик сиёсати ва фойдаланиш шартлари.

## Хавфсизлик
- Бу версияда ҳақиқий аккаунт/махфий маълумот киритманг.
- `localStorage` махфий ёки сезгир маълумотларни сақлаш учун мос эмас.
- API калитларини HTML/JavaScript ичига қўйманг.
- Оммавий ишга туширишдан олдин хавфсизлик, қонуний талаблар, модерация ва маълумотларни ўчириш жараёнларини тайёрланг.
